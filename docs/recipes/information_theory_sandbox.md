# Information Theory Sandbox Recipes

Here are quick, copy-paste recipes to launch, interact with, and programmatic analyze the **Information Theory Sandbox** components.

---

## 1. Quick-Start Launch Recipe

This script instantiates the visual sandbox programmatically and displays the window.

```matlab
% Clear workspace
close all;
clear;

% Instantiate the unified Information Theory Sandbox GUI
app = OceanViz.App.InformationSandbox();

% Show and bring the app window to the front
app.show();

% Display help instructions
disp('Information Theory Sandbox launched successfully!');
disp('Select between the Gambling (Kelly) and Compression tabs to explore.');
```

## 2. Dynamic Timers and Reentrancy Teardown

If you ever want to close and cleanly dispose of any active timers generated by the app to avoid background memory leaks, run this command:

```matlab
% Find all active timers in the MATLAB workspace
activeTimers = timerfindall();
if ~isempty(activeTimers)
    fprintf('Found %d active timers. Stopping and deleting...\n', length(activeTimers));
    stop(activeTimers);
    delete(activeTimers);
else
    disp('No active timers found. Workspace is clean.');
end

% Close all open figures
close all;
```

## 4. Programmatic Verification of Kelly Growth

Analyze the relationship between theoretical expected growth rates and the actual Kelly betting strategies without launching the GUI:

```matlab
% 1. Set true horse winning probabilities
trueProbs = [0.50, 0.25, 0.15, 0.10];

% 2. Define track odds multipliers (Fair vs Unfair)
fairOdds = 1.0 ./ trueProbs;               % [2.0, 4.0, 6.67, 10.0]
unfairOdds = [1.80, 4.50, 5.00, 12.00];    % H2/H4 have high payouts!

% 3. Calculate optimal Kelly betting strategy for unfair odds
% (Kelly allocates bets proportional to trueProbs under fair odds, but optimizes under unfair odds)
kellyBets = OceanMath.Information.Processes.KellyOptimizer.optimize(trueProbs, unfairOdds);

% 4. Compute expected log-growth rate under Kelly strategy
W_kelly = OceanMath.Information.Processes.KellyOptimizer.computeExpectedGrowth(trueProbs, kellyBets, unfairOdds);

% 5. Print analytical findings to console
fprintf('==================================================\n');
fprintf('Kelly Proportional Betting Allocation:\n');
for i = 1:length(trueProbs)
    fprintf('  Horse %d: Prob = %.2f, Odds = %.2f, Bet Fraction = %.3f\n', ...
        i, trueProbs(i), unfairOdds(i), kellyBets(i));
end
fprintf('Theoretical Optimal Expected Log-Growth: %.3f bits/race\n', W_kelly);
fprintf('==================================================\n');
```
